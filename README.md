# silvertrim
A nice skeuomorphic/glossy theme for KDE Plasma.<br>
Plasma theme based on Breeze<br>
Window deco made from scratch
![preview1](https://github.com/Azkuzku/silvertrim-kde-plasma-theme/blob/main/preview-images/preview1.png)
I highly recommend using the [Two Weekend Go](https://gitlab.com/GuitarBro/two-weekend-go) font and [Crystal Remix](https://github.com/dangvd/crystal-remix-icon-theme) icons for style points.
